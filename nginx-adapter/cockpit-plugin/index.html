VHost별 IP 접근 제어 (nginx)

도메인별 nginx vhost의 IP 화이트리스트 관리. /etc/nginx/iprules.d/<domain>.conf 파일을 생성·갱신하고 nginx reload. monitor-nginx.example.com는 vhost에 직접 정의된 자기 잠금 방어 정책(read-only). Imperial 도메인은 monitor 운영자 책임 — IP 잘못 입력 시 사용자 접근 차단되므로 신중히.

재시작 예약

소프트웨어 업데이트(특히 커널 보안 패치) 후 비사용시간 재부팅용. systemd unit enabled + Rootless Docker(appuser Linger=yes) + Docker restart=unless-stopped로 구성되어 부팅 후 자동 복구됩니다. 예약 후 재부팅 직전 wall 메시지가 모든 SSH 세션에 broadcast 됩니다. 범위: 1분 이상, 7일 이내.
